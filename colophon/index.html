How this site is built

A static site that loads instantly, an edge API that costs nothing to run, and a lot of tests.

Static site

Astro pre-renders every page to HTML on GitHub Pages: services, pricing, guides, case studies, tools, RSS, sitemap and social cards generated with satori.

Islands

Only interactive pieces ship JavaScript: catalog search, intake, booking, checkout and the free tools are small Preact islands loaded when they scroll into view.

API

A Cloudflare Worker (Hono) with a D1 database handles leads, availability, bookings, invoices and admin. Inputs are validated with the same zod schemas the browser uses.

Payments

Clients pay to public wallet addresses and submit a transaction hash; the API verifies recipient, amount and confirmations on public explorers. No private keys exist anywhere.

Visibility

Every section, service, tool and case study is public, unlisted, private or off from config. A build integration prunes private pages and keeps noindex pages out of the sitemap.

Quality gates

Unit tests (scheduling, money, verification, shell), Worker integration tests, Playwright end-to-end tests with axe accessibility scans in every mode, and Lighthouse budgets in CI.

Three visual modes

Cinematic, Clean, Editorial — switch with the buttons in the navigation. Each mode is a set of design tokens: palette, type, radii, shadows and motion.
