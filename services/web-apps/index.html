FAQ

Web apps & SaaS, answered.

Who owns the code and the accounts?

You do. Repositories, cloud accounts and domains are created under your ownership (or transferred at handover).

Can you work with my existing codebase?

Yes. Start with a paid consult or code audit, then we scope improvements or new features against the tiers.

How do payments work for larger projects?

Projects over $10k are split into milestones, each with a demo. You only pay for a milestone after you have seen it working.
