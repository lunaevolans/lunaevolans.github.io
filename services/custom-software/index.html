FAQ

Custom software, answered.

Which technology will you use?

Whatever fits your constraints. Tauri (Rust) for tiny, fast cross-platform apps; Qt or native toolkits when you need deep OS integration; Electron when a web team will maintain it. You get a recommendation with trade-offs before anything is built.

Can you support an older or niche Linux distro?

Yes. Packaging targets are part of the scope: AppImage and Flatpak run almost everywhere, and native .deb/.rpm/AUR/Nix packages can be added for specific distros.

Do you handle code signing and notarization?

Yes — Windows Authenticode and Apple notarization are set up in the release pipeline. Certificates are bought in your name so you keep control.
